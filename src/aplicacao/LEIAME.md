# Aplicação: as ações do sistema

Aqui ficam os casos de uso, ou seja, as ações que o sistema oferece: "registrar compra", "consultar fatura", "gerar resumo do mês". Cada ação usa as regras do domínio na ordem certa.

Aqui também ficam as **portas**: interfaces que dizem o que o sistema precisa do mundo de fora (ex.: "algo que saiba salvar lançamentos"), sem dizer como isso é feito.
